## ⭐ Featured project

### [QMAS: Quality Metrics & Analysis System](https://github.com/Robin-Wynn/QMAS-Defect-System-IBM-i)
A full-stack IBM i application that takes manufacturing defect data from a CSV file, calculates its true financial impact, and puts it in front of the managers who need to act on it.

- **Batch side:** validates and loads records with ILE COBOL and embedded SQL, using DB2 lookup tables for cost multipliers
- **Interactive side:** a 5250 green-screen interface with filtering, scrollable subfiles, and a "Critical Escape" warning
- **Automation:** CL wrapper with scheduled nightly runs

🎬 [Watch the demo](https://youtu.be/4kH2d-W_2O0)
